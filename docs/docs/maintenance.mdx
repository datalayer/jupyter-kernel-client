# Maintenance

## Uninstall

```bash
pip uninstall jupyter_kernel_client
```

## Optional Extras

Install optional feature sets as needed:

```bash
pip install "jupyter-kernel-client[kaggle]"
pip install "jupyter-kernel-client[konsole]"
```
