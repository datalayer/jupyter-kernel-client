# Contributing

## Development Install

```bash
pip install -e ".[konsole,test,lint,typing]"
```

## Run Tests

```bash
pip install -e ".[test]"
pytest
```

## Development Uninstall

```bash
pip uninstall jupyter_kernel_client
```

## Packaging

See the repository `RELEASE.md` file at the project root for packaging steps.
